# MarkLens Themes

Themes for the MarkLens Theme Gallery.

- `index.json` lists every theme. Set `featured` to a theme id to pick Theme of the Week, or leave it `null` and MarkLens picks one each week.
- Each theme lives in `themes/` as a `.mltheme` file. Export one from the MarkLens theme editor and drop it in.
- Bump `version` in `index.json` when you change a theme, and people who have it get an Update button.
